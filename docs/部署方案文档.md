# 项目看板部署方案文档

本文档说明如何通过 GitHub Actions 将 `project_dashboard` 自动部署到 GitHub Pages，并用腾讯云 DNS 绑定 `board.huatuo.cloud`（方案 A · CNAME）。链路与 `geek-ppt` 同构。

---

## 1. 准备工作

确保仓库中已包含：

- `.github/workflows/deploy.yml`：push `master` 时构建并发布到 GitHub Pages
- `vite.config.js`：`base: "./"`（相对路径，兼容 Pages 二级路径与自定义域名根路径）

本项目已声明要 CI，允许写入 workflow。

---

## 2. 开启 Pages（【用户操作】）

1. 打开仓库 `https://github.com/huatuo-dr/project_dashboard`
2. **Settings** → **General** → **Change visibility**，将仓库改为 **Public**（Pages 对公开仓免费可用）
3. **Settings** → **Pages**
4. **Build and deployment** → **Source** 选择 **GitHub Actions**（不要选 Deploy from a branch）

---

## 3. 提交与监控 Actions

将部署相关改动合入 / 推送到 `master` 后：

1. 打开仓库 **Actions** 选项卡
2. 工作流名：**Deploy to GitHub Pages**
3. 等待全部步骤变绿

本地验证构建：

```bash
npm i
npm run build
```

---

## 4. 默认访问 URL

部署成功后，先用 GitHub Pages 默认地址验证功能：

`https://huatuo-dr.github.io/project_dashboard/`

应能看到 10 张项目卡片；搜索、封面跳转、「复制链接」正常；页面不展示裸露 URL；封面不破图。

> [!TIP]
> 若样式错乱或封面 404，优先检查 `vite.config.js` 的 `base` 是否为 `"./"`。

---

## 5. 常见问题

### 页面样式错乱或封面加载失败

- 确认 `base: "./"`
- 确认封面路径在 `public/projects.json` 中形如 `/covers/日常工具集.png`，且文件在 `public/covers/`

### Actions 失败

- 确认 Pages Source 已设为 **GitHub Actions**
- 确认仓库为 Public（或账号具备私有仓 Pages 权限）
- 查看失败 step 日志（`npm install` / `npm run build` / `deploy-pages`）

---

## 6. 进阶：自定义域名 `board.huatuo.cloud`

### 方案 A：直接绑定自定义域名（CNAME）——本项目采用

均为【用户操作】：

1. **腾讯云 DNS**
   - 控制台 → DNS 解析 → 域名 `huatuo.cloud`
   - 新增记录：主机记录 `board`，类型 **CNAME**，记录值 `huatuo-dr.github.io`
2. **GitHub Pages**
   - **Settings** → **Pages** → **Custom domain** 填 `board.huatuo.cloud` 并保存
   - 勾选 **Enforce HTTPS**
3. **证书**
   - GitHub 申请 TLS 可能需要 **15–60 分钟**；证书未生效前不要记 Fail，可先用默认 Pages URL 验功能

绑定后访问：`https://board.huatuo.cloud/`

`vite.config.js` 保持 `base: "./"` 即可，无需再改。

### 方案 B：腾讯云 CDN / EdgeOne（未采用）

可将加速域名指向 `huatuo-dr.github.io` 并设置回源 Host，证书在腾讯云侧配置。本项目规格选择方案 A，不采用方案 B。

---

## 7. 配置总结

| 配置项 | 推荐值 | 说明 |
| :--- | :--- | :--- |
| Vite `base` | `"./"` | 兼容默认二级目录与自定义域名根路径 |
| GitHub Pages Source | GitHub Actions | push `master` 自动构建发布 |
| 默认 URL | `https://huatuo-dr.github.io/project_dashboard/` | 证书生效前的验收地址 |
| 自定义域名 | `board.huatuo.cloud` | 腾讯云 DNS CNAME → `huatuo-dr.github.io` |
| HTTPS | Enforce HTTPS | GitHub 侧勾选；证书可能延迟生效 |
